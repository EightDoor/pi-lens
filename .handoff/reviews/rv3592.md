## Cleared under attack
- **False-fire on complete runs.** Stryker's "Instrumented N" count includes every collected mutant, including comment-disabled and static-ignored ones, which later appear as `Ignored`. `augmentAndSummarize` counts every status (`Ignored`, `CompileError`, `RuntimeError`, `Timeout`, `NoCoverage`), so both sides count the same set.
- **Resample path.** `sampled` stays true on every attempt, because `planResample` only runs `if (sampled)`.
- **`--max-files`.** The cap applies before both the measurement and the real run.
- **Unparseable dry-run output.** The `!cost` fallback leaves `costEstimate` null, so the backstop is off.
- **Dropped-partial detection.** On an unsampled run the backstop catches it: the interrupt handler writes only `partialResults` (`mutation-test-report-helper.js:40-47`), so evaluated is less than measured. On a sampled run it is blind by design, and the body says so.
- **Item 1 facts.** Checked against the pinned core/instrumenter 10.0.0: the per-file debug log and aggregate info line, and the order (instrumentation in step 2, the `dryRunOnly` check in step 3).
- **Job classification.** No workflow file changed and no new job was added, so `ci-verdict` classification is unaffected.
