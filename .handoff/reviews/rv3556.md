### F2 (Medium, #3526): bundled short flags and `-t` bypass the mktemp rule
`MKTEMP_DIR_FLAGS` matches only the literal `-d`/`--directory`. The code also treats `-t` as a no-op. I measured on GNU coreutils 9.4 with TMPDIR unset:
```
mktemp -d -t rvprobe.XXXX  -> /tmp/rvprobe.aotI     hook: allow
mktemp -dt rvprobe.XXXX    -> /tmp/rvprobe.1knH     hook: allow
mktemp -dp /tmp rvprobe.XXXX -> /tmp/rvprobe.J15t   hook: allow
mktemp -qd /tmp/pi-lens-review-XXXX                 hook: allow
```
`mktemp -dt X` is the classic idiom. The PR body's shape-16 "measured" claim never covered `-t`. Fix: parse bundled short flags character by character (`d`, `q`, `u`, `t`, `p` with its value taken from the next token). Treat `-t`/`--tmpdir` with a relative template as `$TMPDIR`-rooted.
