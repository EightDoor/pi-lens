**F2 (high): the new seam test is itself load-bound, with the #3493 shape.**
The file is `tests/clients/observed-mutation-time-bound-scale.test.ts`.

The problem is in `onFakeClock`:
- It installs fake timers, starts the operation, advances, then calls `vi.useRealTimers()` before the operation settles.
- Each deadline is computed as a fake-clock `started + bound`.
- The production deadlines are the 50 ms settle per-entry deadline and the 200 ms sweep window. `captureFileStatsForPaths` and `scanTrackedIncrementally` check them against `Date.now()`, which is now the REAL clock.
- So any case that expects the operation to complete (unscaled, "only X named", pinned, or the canary) depends on host speed.

The cost:
- It sits in the gating Unit lane.
- When the canary fails unscaled, the pass exits 2.

Runs at this head, file run alone, with the host also carrying other agents' load (ambient load1 about 20):

| harness | result | first red |
|---|---|---|
| 32 hogs, 6 runs (load 26-41) | **0/6** | `settle at scale=undefined: expected false to be true` |
| 16 hogs, 5 runs | 2/5 | `settle at scale=undefined` / `settle at scale=0` |
| 8 hogs, 5 runs | 4/5 | `settle at scale=undefined` |

The PR body claims 5/5 at 8 hogs. The #3546 row of the same PR uses 32 hogs as its bar.

**Remedy (probed; patch at `F2-remedy.patch`):**
- Keep `setTimeout`, `clearTimeout` and `Date` faked until the operation settles: `return running.finally(() => vi.useRealTimers())`.
- Move the canary advances under the per-entry and window deadlines: settle 49, sweep 199, refresh 199.

**F4 (low; shapes 10 and 13): the production seam is neither gated nor clamped.**
The seam is `scaledBoundMs` at `clients/observed-mutation.ts:184`. With the variables unset it returns `ms` unchanged; that part is verified. The probe drove the built `armObservedMutation` on a 5-file directory:

```
scale=unset -> armed=true      scale=0.2   -> armed=true
scale=10    -> armed=true      scale=1e8   -> armed=false reason=timeout  (TimeoutOverflowWarning ... set to 1)
scale=1e309 -> armed=false reason=timeout   scale=Infinity -> armed=false reason=timeout
scale=NaN/-1/0 -> armed=true   scale=1e-9 bound=captur (typo) -> armed=true   (silently inert)
```

- A "huge" scale inverts to a zero budget. `bounded()` maps a non-finite ms to 0, and Node clamps an overflowing delay to 1 ms.
- The seam is not gated to tests. Its siblings are: `clients/project-snapshot.ts:1801` and `clients/review-graph/builder.ts:2649` read their `PI_LENS_TEST_*` variables only under `NODE_ENV === "test"`, and `clients/env-utils.ts` has `isTestMode()`.
- The pass accepts only `0 < scale < 1` (`scripts/time-bound-scale-pass.mjs` `main()`).
- **Remedy:** `if (!isTestMode()) return ms;` plus `if (!(Number.isFinite(scale) && scale > 0 && scale < 1)) return ms;`.
